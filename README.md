# 🚀 Playwright Enterprise Framework

Enterprise-grade Playwright + Python automation framework built using Pytest, CI/CD, reporting, and scalable Page Object Model architecture.

---

# 📌 Features

✅ Playwright with Python  
✅ Pytest Framework  
✅ Page Object Model (POM)  
✅ HTML Reports  
✅ Allure Reports  
✅ GitHub Actions CI/CD  
✅ Parallel Execution Ready  
✅ Docker Support  
✅ Cross-browser Testing  
✅ Scalable Framework Architecture

---

# 🧠 Tech Stack

- Python
- Playwright
- Pytest
- Pytest HTML
- Allure Reports
- GitHub Actions
- Docker
